# 🧠 Algorithms Implemented

## Uninformed Search

### Breadth First Search (BFS)

* Complete search algorithm
* Explores level by level
* Guarantees shortest path in unweighted graphs

### Depth First Search (DFS)

* Explores deep before backtracking
* Memory efficient

### Uniform Cost Search (UCS)

* Cost-based graph traversal
* Finds optimal path

---

## Informed Search

### A* Search

Features:

* Uses heuristic function
* Optimal and complete
* Efficient pathfinding

### Greedy Best First Search (GBFS)

Features:

* Heuristic-driven search
* Faster exploration
* May not always produce optimal results

---

## Local Search

### Hill Climbing

* Iterative improvement strategy
* Local optimization

### Simulated Annealing

* Probabilistic optimization algorithm
* Avoids local maxima

---

## Game Search

### Minimax Algorithm

* Adversarial search
* Decision-making in games

### Alpha-Beta Pruning

* Optimized Minimax
* Reduces unnecessary search

---

## Evolutionary Computing

### Genetic Algorithm

Features:

* Selection
* Crossover
* Mutation
* Population-based optimization

Run the script:

```bash

```
